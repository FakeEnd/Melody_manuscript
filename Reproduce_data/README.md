# Reproduce_data — regenerating the figure source data

The notebooks in `Reproduce_figure/` plot the manuscript figures **from** the CSV
files in `Data/`. The scripts here go one step further back: they show **how those
CSVs are produced from the Melody model and the raw methylation / meQTL /
scRNA-seq embedding data**.

These scripts are not needed to reproduce the figures (use `Data/` + the
notebooks for that). They are provided so the pipeline — model → evaluation →
source data — is transparent and reproducible in principle. Running them requires
a GPU machine with the model code, a trained checkpoint, the GRCh38 genome, and
(for the per-CpG benchmarks) the cell-type methylation tracks.

## Setup

```bash
pip install numpy pandas scipy scikit-learn torch selene-sdk pyBigWig tqdm
# extra, per figure: Figure 3A/B ISM logos need `tangermeme`; Figure 4 motif
# insertion (Reproduce_data/Figure4/insert_motif.py) needs `pyliftover` (and pyBigWig).
pip install tangermeme pyliftover

export MELODY_CODE=/path/to/Melody        # the public Melody model repository
export CHECKPOINT=/path/to/Melody-MT-39.pth
export GENOME_FA=/path/to/GRCh38.primary_assembly.fa
export BIGWIG_DIR=/path/to/bigwigs        # 39 cell-type methylation tracks (BigWig)
export OUT_DIR=./generated_csv            # regenerated CSVs land here
```

For scripts built on `_engine.py`, paths can also be edited directly in its
`CONFIG` block. The Figure 5 scripts instead take explicit command-line paths;
run them with `--help` to see the required inputs. Regenerated CSVs are written
to `OUT_DIR` (or the path given with `--output-csv`) and are meant to be
**compared against** the committed files in `Data/`, not to overwrite them.

The Figure 2 benchmark scripts additionally rely on two files that ship inside the
Melody code repo and define the validation/test sampling splits: `data/sample.csv`
and the genome at `data/fasta/Homo_sapiens.GRCh38.dna.primary_assembly.fa`
(a symlink to your `GENOME_FA` is fine). The meQTL script needs neither.

```bash
python figure3_meqtl.py        # Figure 3 C–I         (model + bundled meQTL tables)
python figure2_benchmark.py    # Figure 2 A–B, 2G     (checkpoint + genome + BigWig truth)
python figure2_perchr.py       # Figure 2 C, D, E, F  (heavy: whole-genome inference)
python figure5_afgh.py         # Figure 5A; shared evaluation logic for Figure 5F–H
python figure5_b.py            # Figure 5B
python figure5_de.py           # Figure 5D/E
```

## What each panel needs

| CSV | Script | Inputs |
|-----|--------|--------|
| `figure_2AB.csv`, `figure_2G.csv` | `figure2_benchmark.py` | checkpoint + genome + BigWig truth |
| `figure_2C/2D/2E/2F.csv` | `figure2_perchr.py` | checkpoint + genome + BigWig truth (whole genome) |
| `figure_3C/3D/3E/3F/3G/3H/3I.csv` | `figure3_meqtl.py` | checkpoint + genome + bundled meQTL tables |
| `figure_5A.csv`, `figure_5F.csv`, `figure_5G.csv`, `figure_5H.csv` | `figure5_afgh.py` | checkpoint + genome + BigWig truth + scRNA-seq embeddings + held-out regions |
| `figure_5B.csv` | `figure5_b.py` | Melody-G1/G2 checkpoints + genome + 34 BigWig tracks + embeddings + variable-block splits |
| `figure_5D.csv`, `figure_5E.csv` | `figure5_de.py` | score CSV and KEGG report, or checkpoint + genome + gene-KO embeddings + regions for full recomputation |

`Figure 3A/3B` (ISM sequence logos) are produced by
`Reproduce_figure/Figure3_AB_ism.ipynb`. **Figure 4** (motif insertion) source
data is produced by `Reproduce_data/Figure4/insert_motif.py`.

## Metric conventions

* Single-base methylation is the sigmoid of the model output, in `[0, 1]`.
* Per-CpG metrics are computed over CpG positions with a ground-truth QC filter:
  the whole-genome / sampling splits keep truth in `[0, 1]`; the CST split keeps
  truth `>= 0` (only negative labels are excluded), matching the original CST
  evaluation. CST regions are centred in the model window. AUC binarizes truth at 0.5.
* meQTL effect = change in summed methylation in a small window around the CpG
  (`P_alt − P_ref`), averaged over the cell-type tracks matched to the meQTL's
  tissue, divided by the CpG count.
* Track labels follow the published source data: the whole-genome / sampling
  splits of 2A-B use the full BigWig-derived names (`GSM..._Adipocytes-Z...`); the
  CST split and panel 2G use the short cell-type labels (`Adipocytes`).
* Figure 3E is the distance-windowed Pearson within cumulative SNP-CpG distance
  cutoffs. Figure 3H scores each `tgt_dataset`'s meQTLs using `src_dataset`'s
  tracks (so `n_points` follows `tgt`).

## Scope notes

* **Baseline rows** (INTERACT, CpGenie, iDNA-ABT) in Figures 2 and 3 are produced
  by running those baseline models with the same metric definitions; the scripts
  here emit the Melody rows and the baseline rows are concatenated afterwards.
* **Figure 4** (motif analysis) source data is generated by
  `Reproduce_data/Figure4/insert_motif.py`.
* **Figure 5A/F/G/H** share the held-out-cell evaluation engine in
  `figure5_afgh.py`. Panels F–H require separate embedding/configuration runs and
  explicit output paths; the script does not generate all four panels in one run.
* **Figure 5B** recomputes the Melody-G1/G2 rows. INTERACT, ST, and MT results are
  generated separately and concatenated into the committed source CSV.
* **Figure 5D/E** can either post-process an existing gene-score CSV or recompute
  the scores from the model and gene-knockout embeddings.
